# Michael ♥ Donnah — Mobile App Pack

This is the existing Michael × Donnah Love Universe packaged for mobile using Capacitor.

The web app is kept in `www/` and remains HTML + CSS + JavaScript. Capacitor supplies the Android/iOS native shell.

### Important
- The ZIP is a **buildable source project**, not a pre-signed APK/IPA.
- Android APK/AAB builds require Android Studio + Android SDK.
- iOS builds require macOS + Xcode + Apple signing.
- Firebase configuration still needs to be completed if you want the private photo vault to sync across different phones.
