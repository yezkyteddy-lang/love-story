♡ PRIVATE CLOUD SETUP ♡

Make Michael & Donnah see the same memories on every device

Configure Firebase once, then both of you can sign in with your own authorized email and see shared uploads in real time.

Quick setup
  1. Firebase Console → create a project → add a Web App.
  2. Enable Authentication → Email/Password, Firestore Database, and Storage.
  3. Paste the Web App config above and enter the exact two email addresses you will use.
  4. Publish the included firestore.rules and storage.rules to your Firebase project.
  5. Reload the site and sign in on both phones. New photos will then sync live.
Your Firebase Web App config is okay to place in a static site. The actual privacy is enforced by Firebase Authentication and Security Rules.
